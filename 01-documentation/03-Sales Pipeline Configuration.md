
# Sales Pipeline Configuration

## Purpose

The default HubSpot Sales Pipeline was customized to reflect the customer journey of Gochelicious Premium Catering.

## Customized Pipeline

| Stage | Description |
|--------|-------------|
| New Inquiry | A prospective customer makes an enquiry through phone, WhatsApp, social media, email, or referral. |
| Consultation Scheduled | An initial consultation is scheduled to discuss the client's event requirements. |
| Quotation Sent | A customized catering proposal and quotation have been sent to the client. |
| Negotiation | Pricing, menu options, event logistics, or contract details are being discussed. |
| Deposit Received | The client has paid the required deposit, confirming their intent to proceed. |
| Closed Won | The catering service has been successfully secured. |
| Closed Lost | The opportunity did not convert into a booking. |

## Business Value

Customizing the pipeline ensures that every sales opportunity follows a standardized process. This improves visibility into the sales cycle, supports consistent follow-up, and enables more accurate sales forecasting.

## Lessons Learned

- CRM pipelines should reflect actual business operations rather than generic software defaults.
- A well-designed sales pipeline improves collaboration and reporting.
- Standardized stages make customer tracking more efficient.
